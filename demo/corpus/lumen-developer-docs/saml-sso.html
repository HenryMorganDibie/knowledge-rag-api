Configuring SAML Single Sign-On

Lumen Cloud supports SAML 2.0 single sign-on with identity providers such as Microsoft Entra ID, Okta and Google Workspace. SSO configuration requires the admin scope.

Setup steps

In Administration, open Identity and choose Configure SAML. Copy the Assertion Consumer Service URL and Entity ID into your identity provider. Then upload the identity provider metadata XML to Lumen Cloud and send a test login before enforcing SSO for all members.

Attribute mapping

Lumen attributeSAML attributeRequired
emailhttp://schemas.xmlsoap.org/ws/2005/05/identity/claims/emailaddressYes
display_namehttp://schemas.microsoft.com/identity/claims/displaynameNo
groupshttp://schemas.microsoft.com/ws/2008/06/identity/claims/groupsNo

Just-in-time provisioning

When just-in-time provisioning is enabled, a member account is created on first successful SSO login. Group claims are mapped to Lumen roles on every login, so removing a user from a group in the identity provider removes the role at their next sign-in.

Troubleshooting

A clock skew error means the SAML assertion's NotBefore or NotOnOrAfter time is outside the allowed window of 3 minutes. Make sure the identity provider server synchronises its clock with NTP. An audience mismatch error means the Entity ID configured in the identity provider does not exactly match the one shown in Lumen Cloud.
