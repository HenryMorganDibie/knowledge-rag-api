Rate Limits

Lumen Cloud applies rate limits per API key to protect platform stability. Limits are measured over a rolling 60-second window.

Exceeding the limit

When a key exceeds its limit the API responds with HTTP 429 Too Many Requests and error code rate_limited. The Retry-After header gives the number of seconds to wait before retrying. Clients should back off exponentially with jitter rather than retrying immediately.

Concurrency limits

In addition to the per-minute limit, each key may have at most 25 requests in flight at once. Requests above the concurrency limit receive HTTP 429 with error code concurrency_limited and should be retried after an in-flight request completes.

Monitoring usage

Every response includes X-RateLimit-Limit, X-RateLimit-Remaining and X-RateLimit-Reset headers so clients can throttle themselves before they hit the limit.
