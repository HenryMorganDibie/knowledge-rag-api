API Error Codes

Errors are returned as JSON with an error object containing a machine-readable code, a human-readable message and a request_id. Include the request_id when contacting support.

Error reference

HTTP statusCodeMeaning
400invalid_requestThe request body failed validation
401auth_invalid_keyThe API key is missing, malformed or revoked
403insufficient_scopeThe key lacks the scope required for this operation
404not_foundThe resource does not exist or is not visible to this key
409conflictThe resource was modified concurrently; retry with the latest version
429rate_limitedToo many requests; honour the Retry-After header
503service_unavailableTemporary outage; retry with exponential backoff

Retrying safely

Only retry requests that failed with 409, 429 or 5xx status codes. Send an Idempotency-Key header on POST requests so a retried request is never applied twice.
