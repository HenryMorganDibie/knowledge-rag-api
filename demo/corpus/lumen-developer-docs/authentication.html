Authentication and API Keys

Every request to the Lumen Cloud REST API must be authenticated with an API key. Keys are created per workspace and are shown only once at creation time.

Creating an API key

Open Workspace Settings, select API Keys, and choose Create key. Give the key a descriptive name and select the scopes it needs. Copy the key immediately and store it in a secrets manager; Lumen Cloud stores only a hash and cannot display it again.

Sending the key

Send the key in the Authorization header using the Bearer scheme, for example Authorization: Bearer lc_live_xxx. Requests without a valid key receive HTTP 401 with error code auth_invalid_key. Never send keys in query strings, because URLs are written to proxy and server logs.

Scopes

ScopeGrants
documents:readList and read documents and collections
documents:writeCreate, update and delete documents
webhooks:manageRegister and rotate webhook endpoints
adminManage members, billing and SSO settings

Key rotation

Rotate keys at least every 90 days. Create the replacement key first, deploy it, then revoke the old key. A revoked key stops working within 60 seconds across all regions.
